# Yatin Sanjeev Kanekar — Portfolio

This repository contains a static multi-page personal portfolio website for Yatin Sanjeev Kanekar.

Contents:
- HTML files for each page (index.html, about.html, journey.html, etc.)
- CSS in /css (variables.css, style.css)
- JavaScript in /js and /assets/js
- Images in /assets/images

Deploy
- GitHub Pages: push to this repository and enable Pages from the repository settings (publish from branch `master` / root).
- Netlify / Vercel: drag-and-drop the folder or connect the repo and publish; no build step required (Tailwind is used via CDN).

Notes
- The site currently uses Tailwind CSS via CDN. The original master prompt specified Bootstrap 5 — this repo reflects the current implementation in the workspace.
- Add or replace images in `assets/images/` as needed.
